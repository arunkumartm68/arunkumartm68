## 🚀 Featured Project

### [🏠 VRHome](https://github.com/arunkumartm68/VRHome)
**Immersive, browser-based property tours in Virtual Reality.**

Upload a 3D model of a house and walk through it at real-world scale on desktop or inside a **Meta Quest 3 / 3S**. No app install needed.

- 📦 Supports GLB, GLTF, OBJ, FBX, STL, PLY, 3MF, DAE models
- ⚡ Handles large models with a Web Worker parser, mesh merging, and automatic simplification
- 🎨 Repaint walls, place furniture, measure rooms, and drop markers in VR
- ✋ Grab the whole house with both hands to move, scale, and rotate it
- 💾 Fully client-side: models are stored in the browser with IndexedDB
